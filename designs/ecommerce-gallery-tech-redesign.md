# 电商套图 UI 重构方案 · 科技感工作台

> 设计目标：把当前暖色、信息偏少的套图工作台升级为现代 AI 工作台视觉；重点解决截图中「提示词 / 重作」区域局促、重作 inline 小框难用、内容展示不全的问题。

---

## 1. 设计方向

### 1.1 视觉风格：科技暗色 AI 工作台
- 主背景从 `#F6F5F2` 暖灰改为 **深色渐变背景**（`#0B0E14 → #111827`），营造 AI 创作氛围。
- 卡片/面板使用 **玻璃拟态 + 细边框**：`rgba(255,255,255,0.06)` 背景 + `rgba(255,255,255,0.08)` 边框，配合模糊 backdrop。
- 主强调色改为 **科技蓝 `#3B82F6`** + **AI 紫 `#8B5CF6`**，原珊瑚橙 `#FF4D2E` 降级为「生成/行动」专用点缀。
- 文字使用高对比白灰阶梯：`#F9FAFB`（主标题）、`#E5E7EB`（正文）、`#9CA3AF`（次要）、`#6B7280`（禁用/提示）。
- 按钮统一：主按钮用实心蓝，AI 按钮用紫渐变，危险操作用红，成功态用青绿。

### 1.2 核心改动点

| 问题 | 当前实现 | 重构方案 |
|------|----------|----------|
| 整体风格不够科技 | 暖色 `#F6F5F2` 背景、浅色卡片 | 深色背景 + 玻璃拟态卡片 + 霓虹蓝紫强调 |
| 重作展开小框 | `cell-redo-editor` 直接在图片下方展开 96px 高输入区 | 点击「重作」弹出 **RedoModal** 弹框，textarea 更大（200px+），可查看当前提示词 |
| 内容展示不全 | 任务卡片仅显示图 + 标题 + 状态进度 | 卡片补全：模型、比例、分辨率、类型、提示词入口、失败原因、生成耗时等 |
| 提示词入口不够精致 | 紫色小 pill，内容弹框宽度 720 | 改成「提示词溯源」按钮，弹框加宽到 800，双语切换更醒目 |
| 左侧配置偏杂乱 | 区块用线分割，AI 按钮小 | 区块分组卡片化，AI 按钮升级为大号 AI 胶囊，字段标签更紧凑 |

## 3. 组件级重构

### 3.1 左侧配置面板
- 背景：`--g-bg-soft`（#111827）+ 右侧 1px 分隔线 `--g-border-strong`。
- 每个配置区块用 **玻璃卡片**：背景 `--g-bg-elevated`、边框 `--g-border`、圆角 16px、内边距 20px。
- 上传区：拖拽区域改为虚线边框 + 上传图标，hover 时边框变蓝并发光。
- AI 帮写按钮：从 12px 小胶囊改为 14px 大按钮，带 ✨ 图标和紫色渐变。
- 市场/输出配置：折叠面板头部加图标，展开态更明确。

### 3.2 出图规划列表（PlanRow）
- 行卡片深色背景 + 左侧 3px 强调线（极速出图=紫，普通=蓝）。
- 信息更完整：序号、名称、标签、数量、比例、分辨率、模型简称。
- 操作按钮：复制/删除/设置 改为图标按钮，hover 高亮。

### 3.3 任务卡片（创作结果）
- 深色卡片 + 细边框 + 顶部状态彩条。
- 头部显示：创建时间、任务名（可编辑）、状态 badge、模型/总计信息。
- 进度条：蓝到紫渐变，带动画光晕。
- 图片网格：
  - 完成图：hover 显示「下载 / 提示词 / 重作」三层操作。
  - 生成中：脉冲骨架 + 当前状态。
  - 失败：红色提示 + 可重作。
- 操作区：「查看详情」「一键做同款」「发布案例」按钮更分明。

### 3.4 单图操作：提示词 + 重作

#### 提示词
- 按钮改为 **「提示词」+ 紫色 AI 徽标**（与截图一致但精致化）。
- 点击弹框：`width: 800`，顶部双栏头部（图标 + 标题 + 描述）。
- 弹框内：双语切换 pill、提示词文本区（深色代码风）、溯源折叠面板、复制按钮。

#### 重作（核心改动）
- 点击「重作」不再 inline 展开，而是弹出 **RedoModal**。
- 弹框内容：
  - 顶部：当前图片缩略图 + 原标题 + 状态。
  - 中部：大号 textarea（默认 6 行），预填当前中文提示词，可编辑。
  - 底部：取消 / 重新生成（主按钮）。
  - 提示文案：「修改后将按当前中文提示词重新生成单图」。
- 宽度：560px，适合长文本编辑。

### 3.5 弹层通用样式
- Modal / Drawer 统一深色背景、圆角 22px、柔和阴影。
- 关闭按钮 hover 背景加深。
- 表单输入框：深色背景 `#1F2937`、边框 `#374151`、focus 蓝色光环。
- antd 覆盖：同步覆盖 `.g-modal` / `.g-drawer` 下 antd 组件 token。

## 4. 响应式策略

- 桌面：左侧 380px + 右侧 1fr（与现有一致）。
- 平板（< 1280px）：左侧 340px，右侧 padding 减小。
- 手机（< 860px）：单列，配置面板在上，结果区在下，生成按钮吸底。
- 弹框：桌面 800/720/560；平板以下宽度 92vw；手机全屏。
