# 电商套图 UI 重设计规范

> 针对「首屏视觉图 属性设置」弹窗与「AI 智能策划台」抽屉的交互与视觉重构，确保与项目整体配置、设计 token 保持一致。

## 一、设计目标

1. **降低认知负荷**：字段按电商工作流语义分组，避免一列到底的表单项。
2. **强化 AI 帮填**：将「AI 帮填」从标题旁的小按钮升级为每个分组的可感知操作入口。
3. **提升信息密度**：在 960–1080px 弹窗宽度内，使用三栏/卡片式布局，让 6–8 个字段同时可见。
4. **统一策划台体验**：推荐类型按电商套图使用场景分类，增加图标、搜索、已选聚合。
5. **保持一致性**：复用 `gallery.css` 中已有的 `--gb-*` 设计 token，不引入新的品牌色。

## 二、当前问题诊断

### 2.1 属性设置弹窗（TypeSettingsModal）

| 问题 | 影响 |
|------|------|
| 字段一列到底，无分组 | 用户不知道哪些字段决定「主体」、哪些决定「风格」 |
| 标签在左、输入框在右 | 视觉重量分散，移动端适配差 |
| AI 帮填按钮过小 | 功能可发现性低 |
| 通用设置与个性化设置视觉同质 | 无法快速区分「全局继承」与「本类型专属」 |
| 缺少实时提示词反馈 | 用户无法直观感知配置如何影响生成结果 |
| 右侧出图设置、参考图区域堆叠 | 信息层级混乱 |

### 2.2 AI 智能策划台（PlannerDrawer）

| 问题 | 影响 |
|------|------|
| 推荐类型纯文字 2 列网格 | 18 个类型难以快速扫描 |
| 缺少分类/搜索 | 新用户不知道「首屏主图」与「细节图」的区别 |
| 已选类型无聚合预览 | 用户必须滚动列表才能确认已选哪些 |
| 自定义子任务表单字段平铺 | 模型、分辨率、比例、数量等混排，缺乏主次 |
| 模板列表无封面时为空 | 模板价值感不足 |

## 三、设计原则

1. **电商工作流优先**：字段按「产品表达 → 视觉氛围 → 输出控制」顺序组织，而非后端配置顺序。
2. **分组卡片化**：每个分组使用独立卡片，带图标、标题、说明。
3. **AI 辅助显性化**：每个分组标题右侧提供「AI 推荐」按钮，并带 loading/完成状态。
4. **选择即所见**：下拉选项用可点击的 pill/chip 呈现，减少鼠标移动距离。
5. **策划台场景化**：推荐类型按「主图 / 详情 / 卖点 / 对比 / 场景 / 人物 / 包装 / 其他」8 个场景分组。

## 四、属性设置弹窗重设计

### 4.1 布局结构

```
┌─────────────────────────────────────────────────────────────┐
│  {icon} 首屏视觉图 属性设置                  [提示词预览 ▼]  │

├─────────────────────────────────────────────────────────────┤
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐      │
│  │ 产品表达     │  │ 视觉氛围     │  │ 输出控制     │      │
│  │ ✨ AI 推荐   │  │ ✨ AI 推荐   │  │              │      │
│  │ · 面料质感   │  │ · 视觉强化   │  │ · 模型       │      │
│  │ · 展示方式   │  │ · 氛围浓度   │  │ · 出图数量   │      │
│  │ · 工艺细节   │  │ · 背景色调   │  │ · 分辨率/比例│      │
│  │ · 价值聚焦   │  │ · 视觉风格   │  │              │      │
│  └──────────────┘  └──────────────┘  └──────────────┘      │
│  ┌─────────────────────────────────────────────────────┐   │

└─────────────────────────────────────────────────────────────┘
```

### 4.2 字段分组映射（hero 类型示例）

| 分组 | 字段 | 控件形式 |
|------|------|----------|
| **产品表达** | 面料质感、展示方式、工艺细节、价值聚焦 | 带推荐选项的下拉 / 可输入 |
| **视觉氛围** | 视觉强化、氛围浓度、背景色调、视觉风格 | 选项 pill |
| **通用继承** | 文案语种、目标市场、电商平台、文案需求 | 紧凑下拉（仅显示） |
| **输出控制** | 模型、出图数量、分辨率/比例 | 下拉 / 步进器 |
| **补充说明** | 备注 | 文本域 |
| **参考图片** | 参考图、单独商品图 | 上传/图片库 |

### 4.3 交互细节

- **AI 推荐**：点击后按钮进入 loading 状态，填充完成后该分组字段高亮显示「已更新」2 秒。
- **字段提示**：每个字段 label 右侧可放小问号图标，hover 显示该字段对最终画面的影响。
- **提示词预览**：右上角折叠面板，实时展示当前配置生成的提示词片段（调用后端或前端组装）。
- **选择控件**：将 `SingleTagSelect` 升级为 `OptionPills` —— 对于选项 ≤ 8 的字段，渲染为一排可点击 pill；>8 时用下拉。

## 五、AI 智能策划台重设计

### 5.1 布局结构

```
┌────────────────────────────────────────────────────────────┐
│  ✦ AI 智能策划台                                    [✕]    │
│  [推荐类型] [自定义子任务] [已保存模板]                       │
├────────────────────────────────────────────────────────────┤
│  🔍 搜索类型…            [全部 ▼] [仅看未选]                 │
│  ┌────────────┐ ┌────────────┐ ┌────────────┐              │
│  │ 🖼 首屏主图 │ │ 📐 白底图  │ │ 🔍 细节图  │              │
│  │ 首屏视觉图  │ │ 纯白背景   │ │ 特写细节   │              │
│  │ ⚡ 极速出图│ │            │ │            │              │
│  └────────────┘ └────────────┘ └────────────┘              │
│  ── 主图 ──                                                │
│  ── 详情 ──                                                │
│  ── 卖点 / 对比 ──                                          │
│  ── 场景 / 人物 ──                                          │
│  ── 包装 / 物流 / 其他 ──                                   │
│  ┌──────────────────────────────────────────────────────┐  │
│  │ 已选 5 个：首屏视觉图、白底图、细节图、试穿图、场景图 │  │
│  └──────────────────────────────────────────────────────┘  │
│  [取消] [⚡ 极速添加 (5)] [AI 智能策划 (5)]                  │
└────────────────────────────────────────────────────────────┘
```

### 5.2 推荐类型分类

| 场景 | 类型 |
|------|------|
| 主图 | hero（首屏视觉图）、amz（亚马逊主图）、bg（白底图） |
| 详情 | detail（细节图）、detail2（细节标注）、angle（多角度图）、spec（参数图） |
| 卖点 / 对比 | usp（卖点图）、pain（痛点图）、cmp（对比图）、design（设计图） |
| 场景 / 人物 | scene（场景图）、tryon（试穿图）、model（代言图）、buyer（买家秀） |
| 包装 / 物流 | pkg（包装图）、ship（物流图） |
| 其他 | promo（促销海报）、custom（自定义） |

### 5.3 类型卡片设计

- 左侧：场景图标（圆形背景）
- 中部：标题 + 描述 + 标签（极速出图 / 自定义）
- 右侧：圆形选择框（选中时填充品牌紫）
- 悬停：轻微抬升 + 阴影

### 5.4 自定义子任务升级

- 顶部步骤提示：1.填写需求 → 2.上传参考图 → 3.设置输出参数
- 需求描述放在最上，突出为主
- 输出参数折叠为「高级设置」卡片，默认收起

### 5.5 已保存模板升级

- 模板以横向卡片列表展示
- 每个模板显示：封面图（或首字母占位）、名称、包含类型数、应用按钮
- 编辑/删除按钮在悬停时显示

## 六、样式规范

### 6.1 新增 / 复用 Token

- 分组卡片背景：`--gb-surface-2`（#FAF9F6）
- 分组卡片边框：`--gb-line`
- 分组标题字体：`--gb-font-display`，14px，700
- 字段标签字体：12px，600，`--gb-ink-soft`
- AI 推荐按钮：`--gb-ai-purple` 渐变
- 选择 pill：未选 `--gb-surface-2` / 已选 `--gb-ink` 白字
- 分组卡片圆角：`var(--gb-r-md)`（12px）
- 分组卡片内边距：16px

### 6.2 响应式

- 弹窗宽度：1080px（桌面），860px（<1280px），全屏（<820px）
- 三栏在 <860px 时变为单栏堆叠
- 抽屉宽度：520px（桌面），全屏（<520px）
