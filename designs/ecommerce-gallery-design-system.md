### 字体
- **展示**：Space Grotesk（标题/数字/品牌字）
- **正文**：Inter + 中文 PingFang SC / Microsoft YaHei
- 字号阶梯：12 / 13 / 14 / 15 / 16 / 19 / 20 / 26 px

### 间距
4px 基准，8 级（4–48px）。弹窗内边距 32px，表单行距 12px。

### 圆角 / 阴影
- 小元件 8px、中 12px、大卡 16px、弹窗 22px
- 三级阴影 + 弹窗专用 `--sh-modal: 0 24px 64px rgba(27,26,33,.18)`
- 缓动：`cubic-bezier(.22,.61,.36,1)` 无回弹

## 🧱 组件库 — 新增组件

### 策划选型卡片 `.pcard`
- **结构**：左侧标题+描述文字 + 右侧 checkbox 方块
- **默认态**：白底 + 浅灰边
- **hover**：上移 1px + 阴影加深
- **选中态**：珊瑚边框 + 浅珊瑚底 + checkbox 填充珊瑚勾
- **行为**：首次点击 → 选中 + 打开弹窗；再次点击 → 直接打开弹窗
- **特殊项**：「客户痛点展示」截图中有黄色高亮底（可在数据层标记 `highlight:true`）

### AI 帮填按钮 `.btn-aifill`
- 紫色渐变 (`#7C3AED → #6D28D9`)，圆角药丸形
- 文案：`✨ AI帮填(免费)`，右上角对齐于区块标题
- hover 上浮 1px

### 模型选择 Tab `.model-tabs > .model-tab`
- 内嵌 tab 切换组：`通用 | Banana-pro | Gpt-image-2`
- 激活态：深墨底 + 白字；非激活透明
- 用于「出图设置」区的模型切换

### 数字步进器 `.stepper`
- `[−] N [+]` 结构，用于出图数量
- 最小值 1，无边框中间显示数字

### 分辨率选择器 `.res-btns`（活动海报专属）
- 与 model-tabs 同风格：`[1K] [2K] [4K]`
- 替代普通类型的「图片比例」下拉
- 活动海报额外提供「自定义尺寸」比例选项

### 弹窗遮罩 `.modal-overlay`
- 半透明黑 + backdrop blur(4px)
- 点击遮罩关闭，ESC 关闭
- 内容居中偏上，支持滚动

### 确认按钮 `.btn-confirm`
- 荧光绿 `#C8E000`，深色文字
- 「设置完成并关闭」，弹窗底部左侧

### 模板按钮 `.btn-template`
- 白底 + 浅灰边，「另存为模板」

## 🔄 交互流程

```
用户点击「🧠 AI 智能策划台」
  → 策划网格展开（动画 fadeUp）
    → 用户点击某张卡片（如「首屏视觉图」）
      → 卡片变选中状态（珊瑚边+底色）+ 计数 +1
      → 弹出「首屏视觉图 属性设置」模态窗口
        → 左栏：个性化设置（5 个字段）+ AI帮填按钮
        → 左栏：通用设置（6 个下拉）+ AI帮填按钮
        → 右栏上部：补充说明 textarea（2000 字计数）
        → 右栏中部：出图设置（模型 tab / 数量 stepper / 比例 dropdown）
        → 右栏下部：参考图片上传（本地上传 + 图片库）
        → 底部：荧光绿「设置完成并关闭」+ 白色「另存为模板」
    → 可继续点击其他卡片添加更多出图类型
  → 底部生成卡实时更新已选数量和预计积分
```

## ♿ 无障碍

- 弹窗 ESC 关闭 + 遮罩点击关闭
- 语义化 header/aside/main/article/dialog
- 触控 ≥44px（按钮/卡片）
