# 电商套图 · 市场配置联动设计方案（v3.1）

> 模块：电商套图 · AI 智能策划台
> 新增：市场配置模块 + 已选清单 + 设置页（通用设置自动带入）+ 验证通过
> 设计令牌继承 v2 系统（珊瑚红 / AI 紫 / 荧光绿，Space Grotesk + Inter）
> 产出：`designs/market-config.html`（高保真可交互原型，单文件）

## 1. 需求拆解

| 维度 | 要求 | 设计落地 |
|------|------|----------|
| 模块 | 电商套图 | 保留 v2 策划台整体框架 |
| 市场配置 | 平台 / 市场 / 语种 可预设默认 | 新增「市场配置」卡片，作为全局默认值来源 |
| 电商平台默认 | 抖音电商 | `cfg-platform` 默认 `douyin` |
| 目标市场默认 | 中东 | `cfg-market` 默认 `middle-east` |
| 文案语种默认 | 中文 | `cfg-lang` 默认 `zh` |
| 自动带入 | 在 AI 智能策划台添加时，带出配置到通用设置 | 打开属性弹窗时，3 个市场字段由 `marketConfig` 自动填充，并显示「已带入市场配置」徽标 |
| 修改并验证通过 | 可改、可验 | 弹窗内改值→显示「已修改」标签→点「验证配置」生成报告+「✅ 配置验证通过」印章 |

## 2. 设计基础（复用 v2 令牌）

- 品牌主色 `--brand:#FF4D2E`；AI 紫 `--ai-purple:#7C3AED`；确认绿 `--confirm-lime:#C8E000`
- 墨色正文 `#1B1A21`（对比度 ≈14:1，远超 WCAG AA 4.5:1）
- 暖纸底 `--bg:#F6F5F2`，表面白 `#FFF`，圆角 8/12/16/22px
- 缓动 `cubic-bezier(.22,.61,.36,1)`（无回弹）
- 字体：Space Grotesk（展示/数字）+ Inter / 苹方（正文）

## 3. 关键组件

### 市场配置卡片 `.mkt`
- 三段式：电商平台 / 目标市场 / 文案语种（均带 `*` 必填）
- 每个选项下方有「默认：X」提示，符合用户预期
- 「保存默认市场配置」按钮 → 写入 `marketConfig` 并 toast 提示，步骤条①置为完成
- 头部「全局默认」脉冲徽标，强调其来源属性

### 策划选型网格 + 已选清单（v3.1 核心修正）
- 18 种出图类型卡片（继承 v2），**点击=加入「已选清单」，不直接弹窗**（贴合用户习惯）
- 已选清单每行：`序号 · 标题 · 配置标签（自定义 / 数量 / 比例 / 分辨率）· [设置 ›] · [✕]`
- 默认添加配置与用户示例一致：`自定义 · 数量 1 · 比例 3:4 · 分辨率 1K`
- `✕` 移除该项（同步取消网格选中）；`设置 ›` 打开该项的设置页

### 设置页（弹窗）`.modal` — 通用设置联动
- 点清单项的「设置 ›」打开；标题显示类型名 + 本类型配置摘要
- **通用设置自动带入两部分配置**：
  - 市场配置（平台 / 目标市场 / 文案语种）来自 `marketConfig`
  - 本类型出图参数（数量 / 比例 / 分辨率）来自该项添加时的配置
  - 顶部紫色脉冲「已自动带入配置」徽标
- 用户修改任一字段 → 该字段显示黄色「已修改」标签
- 「验证配置」按钮 → 展开验证报告：逐字段列出「自动带入 / 已手动修改 / ✓ 有效」，全部有效时显示「✅ 配置验证通过」印章，步骤条③置为完成

## 4. 交互流程（可验证）

```
① 配置市场（平台=抖音电商 / 市场=中东 / 语种=中文）→ 保存
        ↓ 写入 marketConfig
② 在 AI 智能策划台点击某策划类型 → 进入「已选清单」
        （显示：自定义 · 数量1 · 比例3:4 · 分辨率1K · [设置›] · [✕]）
③ 点该项的「设置 ›」→ 打开设置页
        ↓ 通用设置自动带出 市场配置 + 本类型出图参数（徽标：已自动带入配置）
④ 可修改字段（显示「已修改」）→ 点「验证配置」
        ↓ 生成验证报告 + ✅ 配置验证通过
```

## 5. 无障碍 & 一致性

- 正文对比度 14:1（AA 4.5:1 达标）
- 焦点环：表单珊瑚 2px / 弹窗内紫色 3px（`.focus-ring`）
- 弹窗支持 ESC 关闭、点击遮罩关闭
- 交互元素 ≥44px 触控目标
- 语义标签 `aside / main / section / dialog`，步骤条反映进度
- 市场配置与通用设置共用同一套选项映射（`OPT`），保证两端文案一致、零漂移

## 6. 验证结论

原型已通过 JS 语法校验。在浏览器中可完整走通：保存市场配置 → 添加策划类型进入已选清单 → 点该项「设置 ›」→ 通用设置自动带出（抖音电商/中东/中文 + 数量1/比例3:4/分辨率1K）→ 修改字段 → 验证 → 显示「配置验证通过」。
