# 工作台 · 电商套图 / 我的创作 设计方案（v7 · 左右分栏）

> 本轮核心变更：**电商套图页面重构为左右分栏布局**——左侧固定配置面板（上传→核心卖点→市场配置→全局输出配置→出图规划列表→AI智能策划台→使用说明→立即生成），右侧双Tab（AI创作结果/创作案例）。创作案例分类改为 **全部/美妆/服饰/3C数码/家居/食品**，热门套图示例归入该Tab。AI智能策划台改为弹窗模式。

> 字体 Space Grotesk（标题）+ Inter（正文）。产出：`designs/workbench.html`（单文件高保真可交互原型）。

## 3. 电商套图（v7 左右分栏布局）

> **结构性变更**：从「Hero + 上下两栏」改为 **左右分栏**（`.ecom-split`），左侧 340px 固定配置面板（sticky），右侧弹性双Tab内容区。

### 3.1 左侧配置面板 `.ec-left`（340px，sticky）
从上到下依次排列：

| 模块 | 说明 |
|------|------|
| **上传产品图** | 虚线拖拽上传区 + 「图片库」按钮，标题带红色 ✱ 和「仅支持多视角上传」提示 |
| **核心卖点** | 多行 textarea（预填 5 条提示），右上角紫底「AI撰写」按钮一键填充 |
| **市场配置** | 可收起/展开面板，含 AI 推荐标签；内含：电商平台 / 目标市场 / 文案语种 / 视觉风格（4 个 select） |
| **全局输出配置** | 同样可收起；模型选择 / 分辨率 / 图片比例(2列) / 每个类型出图数(± 步进器) / 「应用配置覆盖列表中所有任务」按钮 |
| **出图规划列表** | 迷你版（已选 N/50个 + 清空），显示已选策划类型摘要或空状态 |

| **使用说明** | 4 条编号说明 + 新手指引链接 |
| **立即生成**（吸底） | 显示消耗积分 + 荧光绿「立即生成」按钮 |

### 3.2 右侧内容区 `.ec-right`

## 4. 设置页（点击「设置 ›」）

层级：**通用设置 置于 个性化设置 之下**（按上一轮需求保留）。

```
弹窗标题：<类型名> · 个性化设置
├─ [已自动带入配置] 紫色脉冲徽标
└─ 个性化设置
   └─ 通用设置（紫色胶囊子标签）
      ├─ 市场配置：电商平台 / 目标市场 / 文案语种 / 视觉风格（自动带入 marketConfig，含默认高级质感风）
      └─ 出图参数：数量 / 比例 / 分辨率（自动带入本类型默认）
```

- 改字段 → 该字段亮「已修改」黄标，清单同步显示「已修改」
- 「验证配置」→ 逐字段报告（市场配置带入 / 本类型默认 / 已手动修改 / ✓ 有效）→ 全有效显示荧光绿「✅ 配置验证通过」印章
- 支持 ESC / 遮罩关闭；焦点环紫 2px

## 5. 我的创作（双 Tab 视图）

> **v6 改动**：将原单一「我的创作」拆为两个同级 **Tab**，不再上下堆叠

### 5.1 Tab 栏 `.creation-tabs`
- 圆角胶囊容器（`border-radius:11px`，浅灰底 + 边框），内含两枚 Tab 按钮
- **AI创作结果**（图标+文字+计数徽标 `386`）— 默认激活态（白底 + 珊瑚红字 + 阴影）
- **创作案例**（图标+文字+计数徽标 `500+`）— 激活时同上
- 切换带 `fadeUp` 动画，面板懒渲染（首次切到「案例」才渲染内容）

### 5.2 AI 创作结果（Tab 1）—— 原「我的创作」
- 统计条：套作品合集 / 累计生成图片 / 本月新增
- 筛选条：平台 × 市场 Segmented Control
- 合集卡片网格：5 图封面 + 标题 + 平台/市场标签 + 查看/继续创作

### 5.3 创作案例（Tab 2）—— 新增灵感库
- **搜索栏**：全宽输入框（placeholder: "搜索案例标题、品类、风格…"），实时过滤
- **分类标签** `caseCats`：9 枚圆角药丸标签（全部/3C数码/家居日用/玩具母婴/珠宝首饰/服装配饰/美妆护肤/食品饮料/运动户外），选中 = 珊瑚红填充
- **富卡片网格** `.inspire-grid`（3 列响应式 → 2 列 → 1 列）
  - 大图区 `icard-img`：4:3 占位图，hover 微缩放 `scale(1.05)` + 整卡上浮 `-4px`
  - 左上角双层角标：来源（紫底 `AI生成`/`原创案例`/`Amazon精选`）+ 套图数（珊瑚红 `N 张套图`）
  - 右下角半透明毛玻璃图数角标
  - 卡片体：品类标签（绿点 + 大写）+ 标题（最多 2 行截断）+ 双按钮行
    - 「查看详情 ›」（描边白底，hover 珊瑚红）
    - 「立即生成同款」（荧光绿渐变实心，阴影发光，hover 上浮）
- 数据：9 条示例案例（覆盖截图中的品类和风格），可扩展

## 6. 无障碍 & 一致性

- 正文对比度 ≥ 14:1（AA 4.5:1 达标）
- 焦点环：紫 2px（导航/按钮/弹窗表单）
- 弹窗 `role="dialog"` + ESC 关闭 + 遮罩关闭
- 语义标签 `aside / nav / main / section / dialog`
- 市场配置与通用设置共用 `PLATFORMS/MARKETS/LANGS/STYLES` 选项映射，两端文案零漂移
- 左侧导航结构与项目 `BasicLayout.tsx` 完全对应，降低落地改造成本

## 7. 验证结论

JS 已通过语法校验，CSS 无残留非法属性。浏览器可完整走通：导航切换（含工作台折叠/激活）→ 电商套图（保存市场配置 / 选类型 / 加入清单 / 设置›）→ 通用设置（位于个性化设置下）自动带出 → 修改 → 验证 → 「配置验证通过」；我的创作筛选与合集展示。
