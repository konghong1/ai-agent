# 聊天媒体展示设计重构 — 概览

## 完成内容

对聊天界面中的图片和视频展示进行了全面设计重构，从嵌入式内联样式升级为独立的组件化架构。

## 新建文件

### `web/src/components/MediaCard/index.tsx`
统一的多媒体卡片组件，包含：
- **ImageCard** — 图片卡片，支持：
  - 渐变加载骨架屏（Shimmer 动画）
  - 悬停浮层提示"点击放大"
  - 三合一操作栏：预览 / 下载 / 复制链接
  - 多图缩略图网格（带交错入场动画、悬停放大效果）
- **VideoCard** — 视频卡片，三种状态：
  - **生成中**：旋转加载 + 脉冲点动画 + 流动顶部条
  - **已完成**：video 播放器 + 下载/复制链接操作栏
  - **失败**：红色提示卡片 + 错误信息
- **VideoCard 状态**：三种状态（生成中 / 已完成 / 失败）

### `web/src/components/MediaLightbox/index.tsx`
增强版灯箱组件：
- **顶部工具栏**：缩放控制 (+/-)、百分比显示、复制链接、下载、关闭
- **键盘导航**：←→ 切换图片、ESC 关闭、+/- 缩放、0 还原
- **鼠标交互**：滚轮缩放、双击放大/还原、拖拽平移（缩放后）
- **左右箭头**：多图前后切换
- **底部缩略条**：显示所有图片缩略图，点击跳转
- **底部提示**：操作提示文字

## 修改文件

### `web/src/pages/ChatInterface/index.tsx`
- 移除旧的 200+ 行嵌入式媒体渲染代码
- 替换为 50 行组件调用
- 新增 Lightbox 状态管理（支持多图导航）
- 新增 `MediaCardStyles` 全局动画注入

## 设计语言

采用「冰霜玻璃 Frost Glass」设计风格：
- 使用项目 CSS 变量系统（`--ice-*`）
- 圆角半径 16px（`--radius-xl`）
- 渐变色背景叠加
- 弹性动画曲线（`cubic-bezier(0.34, 1.56, 0.64, 1)`）
- 交错入场动画（staggered）
- 玻璃态操作按钮 + 毛玻璃背景

## 技术要点
- 组件完全独立，可在其他地方复用
- 零新增依赖
- 通过 TypeScript 类型检查
- 构建成功 (vite build)
