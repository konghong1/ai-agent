# 电商套图 UI 重构 · 完成概览

## 做了什么
把电商套图模块从「暖色、信息偏少」升级为**科技暗色 AI 工作台**风格，并落地到前端代码 + 构建验证。

## 确认的 design（已确定，未臆改需求）
- 深色渐变背景 `#0B0E14 → #111827` + 玻璃拟态卡片 + 细边框
- 科技蓝 `#3B82F6` / AI 紫 `#8B5CF6` 霓虹强调；高对比白灰文字阶梯
- 重作：inline 小框 → 独立 560px `RedoModal`
- 内容补全：任务卡片 & 规划行展示 模型 / 比例 / 分辨率 / 类型 / 提示词入口 / 重作入口

## 落地的 4 个文件
| 文件 | 改动 |
|------|------|
| `gallery.css` | 全面重写 token + 组件样式（计划行左强调线、任务卡状态彩条、redo-modal、1280/860/560 响应式） |
| `index.tsx` | 删 inline 重作，改 `RedoModal` 驱动；规划行补 `model` 字段 |
| `RedoModal.tsx` | 新增重作弹框（缩略图 + 6 行 textarea + 取消/重新生成） |
| `PlanRow.tsx` | 新增 `model` prop + 「模型」chip |
