## Bug 修复：4 个问题

### 1. 切换会话页面卡死 (P0)
- **文件**: `web/src/pages/ChatInterface/index.tsx`
- **根因**: `fetchMessages` 的 `finally` 块无条件重置 `switching` 状态 + `pointerEvents: "none"` 冻结 UI 最多 8 秒
- **修复**: 移除 `switching` 状态和所有 UI 冻结逻辑；添加 `AbortController` 取消过期请求；在 `selectThread`/`deleteThread`/`handleNewThread` 中取消进行中的 fetchMessages
- **效果**: 切换会话时无卡顿感，旧消息保持可见可操作，新消息到达后无缝替换

### 2. ERR_PROXY_CONNECTION_FAILED 媒体加载失败 (P0)
- **根因**: 前端直接用 Agnes AI CDN URL (`platform-outputs.agnes-ai.space`) 渲染 img/video，浏览器代理无法访问
- **修复**:
  - 后端新增 `/api/media/proxy` 端点（`app/api.py`），流式代理 CDN 内容，支持 Range 请求（视频 seek），域名白名单防 SSRF
  - 前端新增 `web/src/services/media.ts` 工具函数 `proxyMediaUrl()`，将 CDN URL 转换为后端代理 URL
  - 修改 `MediaCard/index.tsx`、`MediaLightbox/index.tsx`、`ChatInterface/index.tsx` 中所有 img/video src 和 downloadFile 调用

  - `app/api.py` — 移除 `video_id` 参数传递（`get_video_status()` 和 `watch_video_status()` 两个端点）
