## 修复 React #310 崩溃（Rules of Hooks 违规）

### 现象
前端 UI 重构后，打开「属性设置弹窗」时报 `Uncaught Error: Minified React error #310`（useMemo 相关），整个组件树崩溃。

### 根因
`TypeSettingsModal.tsx` 第 332 行的 `const groupedPersonal = useMemo(...)` 被放在 `if (!type) return null` 之后。
- 弹窗关闭（type=null）：early return 直接退出，该 useMemo 不执行 → 本帧只跑 25 个 hook
- 弹窗打开（type=对象）：不 return，执行到 useMemo → 本帧跑 26 个 hook
- **hook 数量随渲染变化，违反 React Rules of Hooks**，React 19 渲染期直接抛错（生产 minified 即 #310）

### 修复
- 将 `groupedPersonal` 的 `useMemo` 移到 `if (!type) return null` 之前，依赖数组从 `[type.personal]` 改为 `[type]`，函数内加 `if (!type) return []` 守卫 → hook 数量恒定
- 顺带消除 `PlannerDrawer.tsx` 的「组件定义在组件内部」反模式：`TypeCard` 原定义在 `PlannerDrawer` 函数体内（每次渲染生成新函数身份，导致所有类型卡片反复重挂载、丢焦点），抽成模块级组件，通过 props（`isChecked` / `onToggle`）传值

### 验证
- `tsc --noEmit` 零错误
- `vite build` 成功（4289 模块）
