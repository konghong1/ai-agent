## 电商套图 · V12.5 修复生成图乱码尺寸标注

**用户反馈**: 生成图中出现大量乱码数字、尺寸标注、测量线（如 `517Mm`、`201.5cm` 等），即便提示词已声明「无文字」。

**根因分析**:
1. 负面提示词「画面问题」仅含 `水印、文字、logo`，未覆盖 `数字、字母、尺寸标注、测量线、标注箭头、尺码标签、乱码文字`。
2. 多数图像生成模型对英文负面词更敏感，但当前负面提示词纯中文，约束力不足。
3. 参考图忽略提示仅提到「水印 / 价格签 / 背景文字 / 无关标签」，未明确排除「尺寸标注 / 测量线 / 技术图纸线条」，模型可能把参考图上的标注当样本学习。

**修改文件**:
- `app/gallery_config.py` — `NEGATIVE_BASE["画面问题"]` 追加：数字、字母、尺寸标注、测量线、标注箭头、文字标注、尺码标签、乱码文字，以及英文强约束 `no text, no numbers, no letters, no watermark, no logo, no annotations, no measurement marks, no dimension lines, no size labels`。
- `app/gallery_prompt.py` — 零文字约束追加英文括号强调 `(no text, no letters, no numbers, no digits, no watermark, no logo, no typography, no annotations, no measurement marks, no dimension lines, no size labels, no arrows, no callouts, no garbled text, no price tags, no brand names)`；参考图忽略提示追加 `尺寸标注 / 测量线 / 标注箭头 / 尺码信息 / 技术图纸线条请全部忽略，不要以任何形式复制到生成图`。
