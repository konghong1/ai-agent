# 2026-07-02

## 多模型提供商聊天页面改造

实现了高扩展性的多模型 LLM 调用架构：

### 新建模块 `app/llm/`
- `base.py` - LLMAdapter 抽象基类（定义 chat() 和 chat_stream() 方法）
- `openai_compat.py` - OpenAICompatibleAdapter（兼容所有 OpenAI 格式端点）
- `qwen.py` - QwenAdapter（通义千问适配器）
- `__init__.py` - LLMFactory 工厂 + PROVIDER_MAP 注册中心
- LLMConfig 数据类（统一配置）

### 核心架构：Factory + Adapter 模式
```
LLMFactory -> PROVIDER_MAP -> LLMAdapter 子类
```
新增厂商只需：写适配器类 + 注册到 PROVIDER_MAP

### 后端修改
- `app/schemas.py` - ChatRequest 增加 provider_type 字段
- `app/agent.py` - 重构为使用 LLMFactory 创建 LLM
- `app/api.py` - /chat 传递 provider_type；新增 /api/chat-stream SSE 端点

### 前端修改
- `web/src/stores/useChatSelectors.ts` - 增加 providerType 字段
- `web/src/components/ChatSelector.tsx` - 透传 provider_type，显示厂商标签
- `web/src/pages/ChatInterface/index.tsx` - 发送消息带 provider_type，使用 SSE 流式
- `web/src/pages/AgentDetail/index.tsx` - 加入 ChatSelector 组件，支持 SSE

### 效果
- 聊天页面可在运行时切换不同 Provider 的模型
- Agent 详情页也可选择不同模型
- 支持 SSE 流式输出
- 架构可扩展至无限厂商
