# 2026-07-06 工作日志

## Docker 多数据库切换方案（已完成）

### 背景
项目 Docker 环境中存在 MySQL/PostgreSQL 配置矛盾：
- `docker-compose.yml` 使用 MySQL 8.0
- `docker/.env` 配置的是 PostgreSQL
- 代码中多处硬编码了数据库连接字符串

### 修改文件清单

1. **新增 `docker/db/init_postgresql.sql`** — PostgreSQL 初始化 SQL 脚本，完整映射 `app/models` 中的所有表
2. **修改 `docker/docker-compose.yml`** — 支持通过 `DATABASE_TYPE` 切换 MySQL/PostgreSQL，添加 PostgreSQL 服务模板（注释）
3. **修改 `docker/.env`** — 添加 `DATABASE_TYPE`、MySQL/PostgreSQL 两组配置参数
4. **修改 `docker/.env.example`** — 同上结构
5. **修改 `docker/Dockerfile.api`** — 同时预装 `pymysql` 和 `psycopg2-binary`
6. **修改 `app/db/__init__.py`** — `wait_for_database()` 自动检测数据库类型，`seed_database()` 不再硬编码
7. **修改 `app/worker/media_worker.py`** — `DATABASE_URL` 从环境变量读取，使用 ORM 正确查询
8. **修改 `requirements.txt`** — 添加 `pymysql>=1.1.0` 和 `psycopg2-binary>=2.9.0`

### 切换方式

用户在 `docker/.env` 中设置 `DATABASE_TYPE=mysql|postgresql`，然后：
```bash
docker compose down -v
docker compose up -d --build
```
