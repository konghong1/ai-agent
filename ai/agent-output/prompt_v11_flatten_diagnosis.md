# 生成图「扁胖」问题诊断与修复

## 现象

- 原图：竖版修身连衣裙（高明显大于宽，立体展示）。
- 生成图：裙子被横向拉宽、纵向压短，呈「矮胖」平铺状，且周围多出相机/眼镜等道具。

## 根因排查

### 1. 前端展示层 → 不是原因

检查了详情弹窗 `.detail-img`、结果网格 `.result-grid`、缩略图 `.thumb`、任务卡片 `.task-cell` 等展示样式：

- 均使用 `object-fit: contain`；
- 没有 `object-fit: fill / cover` 或固定 `width/height` 拉伸；
- 容器固定高度只会造成留白，不会把图片压扁。

**结论：图片本身生成出来就是扁胖的，不是前端展示压扁。**

### 2. 后端出图尺寸 → 主要原因之一

`gallery_service._ratio_to_size` 原逻辑：

```python
return mapping.get(ratio or "", "1024x1024")
```

用户选择「自适应尺寸」时，函数返回 `1024x1024`，直接把出图尺寸锁死为正方形。
连衣裙原图是竖版，被强制输出成 1024×1024 方图，是「扁胖」的重要来源。

**修复**：

- `_ratio_to_size(ratio, reference_filename)` 增加参考图文件名参数；
- 当 ratio 为「自适应尺寸」时，读取参考图实际宽高比，匹配最接近的生成尺寸；
- 无参考图或读取失败时才回退到 `None`（由模型默认）。

验证：

```text
参考图 800×1200（竖版 2:3） → 推断生成尺寸 704×1024
参考图 1600×900（横版 16:9） → 推断生成尺寸 1024×576
参考图 1000×1000（方图）     → 推断生成尺寸 1024×1024
```

### 3. 提示词构图 → 另一个重要原因

用户贴出的提示词里有：

```text
产品呈现：产品平铺俯拍，清晰呈现平面结构与整体轮廓。
```

该句来自「产品呈现」字段选择为「平铺展示」。平铺俯拍本身就会把立体服装展开成平面，视觉上横向变宽、纵向变短，形成「扁胖」感。

**这不是系统 bug，是用户选择了「平铺展示」构图。** 若要保留原图立体修身效果，应在「产品呈现」里选择「整体展示」或「3/4 角度」等不展开商品的选项。

### 4. 提示词里写死的「1:1 正方形构图」→ 已在前一轮修复

用户贴出的提示词仍含 `1:1 正方形构图`，说明该图是在 V11 修复前生成，或服务未重启。
当前代码已改为：

```text
按参考图比例自适应构图，保持画面自然比例
```

不再写死 1:1。

## 修复后的完整链路

1. 用户选「自适应尺寸」；
2. 后端读取参考图实际比例 → 推断生成尺寸（竖版连衣裙 → 704×1024）；
3. 提示词写入「按参考图比例自适应构图，保持画面自然比例」；
4. 不再出现「1:1 正方形构图」；
5. 同时建议用户把「产品呈现」从「平铺展示」改为「整体展示」，避免平铺展开导致的扁胖。

## 生效方式

改的是后端出图与提示词引擎，需重启 `ai-agent-api` + `ai-agent-worker`，前端 `Ctrl+F5` 后重新生成才会生效。

## 给用户的操作建议

若希望生成的图保持原图立体修长比例：

1. 图片大小选择「自适应尺寸」（系统现在会按参考图比例自动出竖版图）；
2. 「产品呈现」不要选「平铺展示」，建议选「整体展示」或「3/4 角度」；
3. 服务重启后重新生成。
