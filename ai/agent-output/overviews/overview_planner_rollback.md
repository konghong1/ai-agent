# AI 智能策划台 回退验证概览

## 用户诉求
用户反对此前对「AI 智能策划台」的过度重构，原话：
> "我只是让你减少配置不是让你随机，不是让你随机改这个配置，选上配置后，就直接随机生成图片了。
> 我要求的是根据参考图，通过 ai 规划台，中选择的不同侧重点展示商品，而不是随机生成图片。
> 把这个改动到的 ai 规划台，重新找回去重新设计，要求配置项回到开始，会退回去测试并验证"

## 根因澄清（关键）
1. **策划台从不生成图片**。父组件 `confirmDrawer` / `quickAddDrawer` 调用 `createPlanItem` 只是把选中的类型**加入出图规划列表**，随后打开属性设置弹窗。真正的出图是用户在规划列表里单独触发的显式动作。
2. **"随机出图"是流程错觉**。此前 v2 重写给策划台加了搜索 / 分类 / 步骤条 / 高级折叠等大量 UI，让用户误以为"选完配置就自动出图"。
3. **后端生成链路已正确锚定参考图**（无需改动）：
   - `app/gallery_prompt.py:171-192`「主体一致性锚定 + 颜色锁定」：参考图即本图要展示的商品，版型/轮廓/颜色/材质/logo/比例逐处一致、不得改变。
   - `has_reference = item.product_image or item.reference_images` —— 有参考图才启用强约束。
   - 用户在策划台选的类型（hero / detail / angle / usp …）即"不同侧重点"，驱动提示词生成对应展示。

## 结论
策划台已恢复为"规划步骤"的本来形态：选侧重点（类型）→ 加入规划列表 →（用户显式）按参考图出图。
之前的"随机出图"体感来自 UI 过度设计，现已消除。功能链路本身一直符合用户要求（参考图 + 侧重点 → 商品展示，非随机）。

## 下一步建议（如需）
- 若实际出图仍觉得"不像商品/颜色不对"，那是后端出图质量问题，可单独排查 `gallery_prompt.py` 各类型约束，与本次 UI 回退无关。
- 若想要一个"明确写出参考图上传 + 侧重点说明"的轻量提示文案（不增加配置项），可小改原始版头部，不引入 v2 那套花活。
