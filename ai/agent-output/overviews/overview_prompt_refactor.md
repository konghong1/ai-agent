## 三、关键差异对照

| 维度 | 重构前 | 重构后 |
| --- | --- | --- |
| 文案规则 | 无 `copy_need` 时写「零文字」，有 `copy_need` 时又写「允许少量版面文案」——自相矛盾 | 仅 `CopyPolicy` 决定；首屏视觉图=零文字，海报/卖点图=允许少量；二者绝不同时出现 |
| 中东适配 | `target_market=中东` 仅当字符串透传，无对应视觉档案 | 自动注入中东主体/肤色/姿容/暖金宝石蓝色系/浅金背景/规避项 |
| 平台规范 | 无 | 注入居中全身构图、主体占比 65%、8K 商业精修、平台禁忌清单 |
| 抽象词量化 | `高级质感风`/`高饱和色调` 原样输出 | 映射为影棚柔光/面料纹理/低灰度高饱和等可识别视觉指令 |
| 卖点处理 | 「核心卖点：<原文>」易诱导把文字印图上 | 「仅用光/面料/姿态体现，绝不转为图上文字」明确视觉转译 |
| 禁止项 | 散落 3 处（M5+末尾+参考图段） | 汇总为 M6 一处绝对禁止清单 |
| 自检 | 无 | `Linter` 生成期拦截自相矛盾与缺要素 |
