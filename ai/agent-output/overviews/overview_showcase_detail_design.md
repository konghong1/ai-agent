# 创作案例详情展示设计方案

## 目标
将「发布到创作案例」后的详情页，从当前的“左侧原图 + 右侧生成图网格”改造成用户参考图所示的电商卖点展示卡片：
- 左侧大封面（产品原图）
- 右侧卖点图卡片 + 缩略图条带
- 下方分类 + 标题 +「立即生成同款」CTA

## 参考图结构分析

```
┌────────────────────┬─────────────────────┐
│                    │  ◉ Luxury Lace      │
│   [产品原图]        │    Neckline         │
│   原图 badge       ├─────────────────────┤
│                    │  ◉ Buttery Soft     │
│                    │    Faux Leather     │
├────────────────────┤  ┌──┬──┬──┬──┐ +6   │
│                    │  │  │  │  │       │
│                    │  └──┴──┴──┴──┘      │
└────────────────────┴─────────────────────┘
   服装鞋帽
   黑色蕾丝拼接皮质吊带连衣裙
   [ 立即生成同款 > ]
```

## 数据组织（不改后端 schema 的 MVP 方案）

当前 `GalleryShowcase` 已有字段：
- `original_url`: 产品原图
- `image_urls`: 选中的生成图列表
- `name`: 案例标题
- `category`: 分类
- `total_count`: 图片总数

**封面图**：默认使用 `original_url`（产品原图），与参考图一致。
**卖点图**：使用 `image_urls` 前 3 张作为右侧卖点卡片。
**缩略图条带**：展示全部 `image_urls`，最多显示 4 张，超出显示 `+N`。

> 后续如需要“把某张生成图设为封面”，可在 `gallery_showcases` 表增加 `cover_record_id` 字段并扩展发布弹窗的封面选择器；本次方案先使用产品原图作为封面，对齐参考图。

```

├────────────────────────────────────┤
│  案例标题 ...                        │
```

- 封面预览使用当前项目的产品原图（从任务或项目中读取）。
- 选择成图仍保持现有的 140×140 固定框勾选。

## 创作案例详情页改造

### 布局
使用新的 `.case-detail-layout` 替代当前 `.detail-layout`：

```
┌──────────────────────────────────────────────────────┐
│                                                      │
│  ┌──────────────────┬──────────────────────────┐    │
│  │                  │  ┌────┐  ┌────┐        │    │
│  │   原图 (cover)    │  │卖点1│  │卖点2│        │    │
│  │   object-fit:    │  └────┘  └────┘        │    │
│  │   contain        │  ┌────┐  ┌────┐┌──┬──┐ │    │
│  │                  │  │卖点3│  │  │  │  │  │ │    │
│  │                  │  └────┘  └──┴──┴──┴──┘ │    │
│  └──────────────────┴──────────────────────────┘    │
│                                                      │
│  服装鞋帽                                            │
│  黑色蕾丝拼接皮质吊带连衣裙                            │
│  [ 立即生成同款 ]                                    │
│                                                      │
└──────────────────────────────────────────────────────┘
```

### 样式要点
- 左侧封面区固定宽度（约 45%），背景浅色，图片 `contain` 居中，带「原图」角标。
- 右侧分上下两部分：
  - 上部：卖点卡片网格（2 列），每张卡片固定比例框，图片 `contain`，标题覆盖在底部。
  - 下部：缩略图横向条带，小图 `contain`，最后一张显示 `+N` 遮罩。
- 下方信息区：分类小字 + 标题 + 主 CTA「立即生成同款」。
- 响应式：小屏改为单列，卖点图全宽，缩略图条带保持横向滚动。

## 复用现有资源

`gallery.css` 中已有 `.set-feature` / `.set-showcase` / `.set-hero` / `.set-grid` / `.set-card` 等样式块，结构几乎一致。方案：
- 保留这些类名，将 `object-fit: cover` 改为 `contain`（避免裁切产品/生成图）。
- 在「创作案例详情」弹窗中使用 `.set-feature` 作为外层，替换当前 `.detail-layout`。
- 新增 `.case-detail-footer` 信息/CTA 区样式。
