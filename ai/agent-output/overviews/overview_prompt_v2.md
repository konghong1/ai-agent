# 电商套图 · 提示词生成引擎 二次优化说明

## 一、你开头的两个问题

**Q：这两段提示词有啥区别？**
→ **没有任何区别，是同一段文本粘贴了两遍**。逐字比对：平台、中东受众、8K 画质、65% 构图、中东模特标准、浅金米杏背景、光影色调、品质表达、文字禁令、禁止项、收尾句完全一致，只是复制重复。所以"区别"为 0。

**Q：有啥问题？**
→ 你列的 4 大类问题都成立，且根因在「配置没真正驱动提示词」。实证后定位到三处真问题（见下）。

## 二、根因（实证，非猜测）

用当前引擎跑了三组配置对比，确认：
1. **冗余**：`STYLE_VOCAB` 里旧「品质细节」与「价值暗示」是**完全相同字符串** → 同一句"面料垂坠肌理…"在 M3、M4 各出现一次。
2. **差异化弱**：M1/M2/M5/M6 全是静态档案占 prompt 大半，用户选项只在 M3/M4 以短短语出现，且多选项映射到近义 vocab → 不同配置生成的 prompt 过于相似 → 图像模型不敏感 → **"配置变了图没变"**。
3. **缺约束**：中东未要求遮盖肩颈/无暴露剪裁、无修图规范、无单主色规则、站姿未量化、hero/tryon 无服装品类字段。

## 三、对应你 4 类问题的修复

| 你提的问题 | 修复做法 |
|---|---|
| ① 重复冗余（品质表达两次 / 背景氛围多次 / 收尾兜底重复） | 品质质感改为**单一事实源**，整段 prompt 只出现一次；新增 `_dedupe` 去重整段重复；删除「价值暗示=品质细节」的二次输出 |
| ② 模糊无量化（色调只给色系、低对比撞色模糊、无服装品类、站姿无参考） | 中东 palette 加「**任选其一作为服装主色**」；站姿量化「**正面微侧约30°**」；新增「**服装品类**」字段(连衣裙/套装/上衣…)；价值聚焦映射为具体视觉重心指令 |
| ③ 结构混乱（模块杂糅、禁止项分散） | 引擎本就是 M1→M6 分层（基础规范→主体→产品视觉→风格→文字约束→禁止清单），本次进一步把「价值暗示」收归 M3 统一处理，杜绝 M4 二次散落 |
| ④ 缺中东/平台隐性约束 | 中东补「**服装完整遮盖肩颈，拒绝暴露剪裁**」；全局补「**修图规范：自然肤质精修，不夸张瘦脸塑形，面料色彩1:1真实还原**」 |

## 四、关键修复：配置不同 → 提示词明显不同

重写 `_assemble`，让每个配置选项映射为**互不相同的具象视觉指令**：
- `价值聚焦`(品质/功能/价格/情感/场景/设计/服务) → 各自专属"视觉重心…"句
- `价值暗示`(稀有材料/工艺精度/设计奖项/用户好评/品牌背书) → 各自专属"以…暗示价值"句
- `视觉强化`(质感放大/色彩冲击/动态模糊/光影对比/虚实结合/构图张力) → 各自专属句

实测（中东+淘宝天猫+hero）：
- A（高级质感/高饱和/连衣裙/聚焦品质）≠ B（科技未来/暗黑/套装/聚焦设计）≠ C（高级质感/低饱和/上衣/聚焦功能）→ **三者 prompt 明显不同**
- A vs B 差异字符数 52，且各自选项名称均落地到 prompt
