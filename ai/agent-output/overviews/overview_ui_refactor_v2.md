# 电商套图 UI 重构 — 验证完成

## 完成内容

### 1. TypeSettingsModal.tsx — 属性设置弹窗 V2

**布局重构**：从旧版两栏改为分组卡片网格 + 底部三栏

- **字段分组**（`GROUP_ORDER`）：按电商工作流语义将个性化字段分为四组
  - 产品表达（品类/面料/展示方式/工艺/价值聚焦/卖点/文案/痛点/方案/对比/情绪/场景/细节…）
  - 视觉氛围（视觉强化/氛围浓度/背景色调/视觉风格/光影/情感/构图/互动/色调/配色）
  - 人物设定（人种肤色/性别物种/年龄维度/身型身材/穿着风格/动作姿态/表情神态）
  - 其他（未匹配的字段自动归入）
- **OptionPills 组件**：选项 ≤7 时渲染为可点击 pill（点击选中/取消），>7 时自动回退为下拉选择。支持"+ 自定义"入口
- **FieldGroup 卡片**：每组带 SVG 图标、标题、分组级 AI 推荐按钮（独立 loading spinner + 高亮动画）
- **提示词预览**：顶部预览开关，展开后实时显示当前配置生成的提示词摘要
- **底部三栏**：补充说明（TextArea） | 参考图片（上传/图库，最多4张） | 单独商品图（上传/项目图选择）

### 2. PlannerDrawer.tsx — AI 智能策划台 V2

**推荐类型区**：
- **搜索栏**：实时按标题/描述搜索类型
- **分类筛选**：6 个场景分类 pill（主图/详情/卖点对比/场景人物/包装物流/其他）
- **仅看未选**：快速筛选尚未添加的类型
- **分组列表**：按分类分组展示，每组带标题
- **类型卡片 V2**：带 SVG 图标（每个类型独立图标）、标题、描述、选中状态

**自定义子任务**：
- **步骤指示器**：3 步流程（填写需求 → 上传参考 → 输出设置），已完成的步骤高亮
- **高级输出设置**：默认收起的折叠面板，包含模型/分辨率/比例/数量

**已保存模板**：
- 横向卡片，封面缺失时显示首字母占位
- hover 显示编辑/删除按钮

**底部已选摘要**：
- 显示已选类型 pill 列表，支持点击 ✕ 移除
- 计数显示已选数量

### 3. gallery.css — 新增样式

- 所有 V2 组件样式类已补充，使用 `--gb-*` 设计 token 保持视觉一致性
- 包含响应式断点（≤900px 单列）
- 动画效果：分组高亮、pill 入场动画、AI spinner
