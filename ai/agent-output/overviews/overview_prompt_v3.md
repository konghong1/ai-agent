# 电商套图提示词引擎 V3：人物判定 + 配置差异化

> 针对反馈：「改了配置生成的图片风格都差不多，而且总带人物构图」。

## 根因（已用探针验证）
- **人物被无条件塞入每种图**：`gallery_prompt.py` M2 段只看 `market.subject`、不看类型，导致 `白底图 / 细节特写 / 多角度` 等纯产品类型也强制出现「主体人物要求：年轻女性模特…」。
- **改配置几乎不改画面**：`科技风` vs `清新风` 提示词只差最后一句 `整体视觉风格：xxx`，市场调色板只在 `高饱和` 时才注入，所以换市场/风格画面雷同。

## 改动
### 1. 按「类型 + 填写字段」决定人物（根治人物构图）
`app/gallery_prompt.py`
- 新增 `_wants_human(type_id, personal)`：`试穿/代言/买家秀` 强制人物；其余类型默认无人物，仅当填写了人物信号字段（人种肤色/性别物种/年龄维度/身型身材/穿着风格/动作姿态/表情神态）才出现人物。
- M2 段：有人物 → 注入市场人物要求 + 人物字段；无人物 → 明确写「无人物：画面仅展示产品/主体本身，不出现任何真人、模特、代言人…」。
- 非人物场景用 `_to_product_composition()` 净化构图/占比措辞（「人物」→「产品」、去掉站姿暗示）。
- 品质质感描述按有无人物/服装切换「面料」/「材质」措辞。

### 2. 市场调色板无条件注入（换市场即换配色）
M4 段：只要市场有 `palette`，色调行末尾追加 `；配色参考{市场调色板}`。不再卡「高饱和」。

### 3. 逐类型版式差异化（让「类型」配置明显改变画面）
`app/gallery_config.py` 新增 `TYPE_LAYOUT` 字典（19 个类型各自的版式/构图指令，如白底图=纯白居中、细节图=超大特写、对比图=左右分屏），`_assemble` 在 M1 注入「版式要求：…」。

### 4. 风格映射强化
`STYLE_VOCAB` 的 `高级质感风/清新自然风/科技未来感` 等升级为多维度视觉描述（光效+色温+质感+氛围），不再是一句空话。

## 验证
- 单元测试 14 项全绿（`tests/test_gallery_prompt.py`），新增 4 项回归：
  - `test_product_type_has_no_human`：纯产品类型无人物、构图净化
  - `test_human_type_with_fields`：填人物字段的 hero 仍注入人物
  - `test_palette_injected_for_any_tone`：调色板无条件注入
  - `test_type_layout_differentiation`：不同类型版式明显不同
- 探针对比：白底图/细节图/首屏图(仅服装品类) 人物判定均为 `False`，试穿为 `True`。
- docker `api` + `worker` 已重启加载新代码。

## 使用
浏览器访问 `http://localhost/`（docker web），**Ctrl+F5** 刷新，对套图重新生成即可看到：纯产品类型不再出现人物，换市场/风格/类型画面差异明显。
