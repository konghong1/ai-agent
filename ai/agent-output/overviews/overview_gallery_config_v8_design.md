# 电商套图 · 配置项与提示词重构方案 V8

## 一、设计原则（电商转化视角）

从「电商分析师 + 电商产品描述」视角出发，所有推荐类型的配置项只围绕一个目标：
**让买家在 0.3 秒内看懂商品、产生兴趣、建立信任、愿意点击/转化。**

因此，全部字段统一收敛到 5 个核心转化维度（以首屏视觉图当前字段为基准）：

| 维度 | 电商问题 | 字段名 | 作用 |
|---|---|---|---|
| 价值聚焦 | 这张图想让买家记住什么？ | 价值聚焦 | 决定视觉重心和卖点 |
| 视觉强化 | 如何一眼抓住注意力？ | 视觉强化 | 构图/光影/色彩钩子 |
| 产品呈现 | 商品以什么状态出现？ | 产品呈现 | 角度/展示方式/完整性 |
| 氛围浓度 | 画面要给买家什么感觉？ | 氛围浓度 | 场景氛围占比与情绪 |
| 价值暗示 | 凭什么让买家相信品质？ | 价值暗示 | 信任背书/品质暗示 |

> 所有类型只从这 5 个维度 + 少量「类型专属必要字段」中选取，
> 拒绝堆砌技术参数（如「视角数量」「特写程度」「标注方式」等），让配置项真正服务于画面转化。

## 三、提示词重构策略

### 1. 配置项 → 提示词映射层

新增「电商转化语义映射」：把 5 个统一字段翻译为具体的视觉指令，而不是把用户输入原样塞进提示词。

| 字段 | 映射方向 | 示例 |
|---|---|---|
| 价值聚焦 | 视觉重心 + 卖点类型 | 聚焦品质 → 质感/工艺特写；聚焦价格 → 性价比暗示；聚焦情感 → 情绪氛围 |
| 视觉强化 | 构图/光影/色彩钩子 | 色彩冲击 → 产品主体与背景低对比层次；构图张力 → 非常规角度；光影对比 → 强反差 |
| 产品呈现 | 主体状态 | 整体展示 / 局部特写 / 悬浮 / 手持 / 平铺 / 穿着 |
| 氛围浓度 | 场景占比 | 极简纯色 / 轻度氛围 / 中度氛围 / 强氛围 |
| 价值暗示 | 信任线索 | 工艺精度 / 材质稀有 / 品牌背书 / 用户好评氛围 |

### 2. 提示词分层结构（M1-M6 保留，注入内容重构）

- **M1 基础规范**：标题、平台、市场、分辨率、主体一致性（参考图锚定）。
- **M2 主体**：人物 or 产品，由类型决定，不再让用户填 8 个人物参数。
- **M3 转化语义**：把 5 个字段的映射结果注入，成为画面核心指令。
- **M4 视觉风格**：visual_style + tone_tendency 量化。
- **M5 文字策略**：允许文字的类型（promo/usp/detail2）才能放文案。
- **M6 禁止清单**：与之前一致。

### 3. 人物类型简化

试穿/代言/买家秀 不再让用户填「人种/性别/年龄/身型」等字段，而是：
- 由 `target_market` 市场档案提供人物基础描述（已存在）。
- 由「产品呈现」字段决定动作/姿态（如：手持、佩戴、展示、穿着）。
- 由「氛围浓度」决定场景复杂度。
- 由「价值聚焦」决定人物与产品的互动重心。

### 4. 输出要求

- 保持「主体一致性 + 颜色锁定」最强约束（参考图商品不变）。
- 每个字段都必须在提示词中有明确落点，杜绝静默丢弃。
- 提示词整体更短、更聚焦，避免 3000 字长 prompt 稀释重点。

## 四、验证方案

1. 修改 `gallery_config.py`：更新 `TYPE_PERSONAL`、补齐 `PERSONAL_OPTIONS` 映射、递增 `GALLERY_CONFIG_VERSION` 强制刷新库。
2. 修改 `gallery_prompt.py`：新增 5 维度语义映射，重写 `_assemble` 的 M3 注入逻辑，删除旧的人物字段硬编码处理。
3. 单元测试：对 18 个类型分别生成提示词，检查：
   - 每个字段都出现在提示词中
   - 无自相矛盾
   - 有参考图时主体一致性锚定存在
4. 编译/启动：FastAPI 正常启动，`GET /api/gallery/types` 返回新字段。

## 五、范围边界

- **只改**：`gallery_config.py`（配置项）、`gallery_prompt.py`（提示词生成）。
- **不改**：前后端路由、数据库 schema、前端 UI、文件存储、模型调用链路。
- 前端弹窗会自动读取新字段并渲染，无需前端改动。
