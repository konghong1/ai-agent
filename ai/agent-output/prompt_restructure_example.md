# 重构后的提示词示例（V10 结构化）

## 亚马逊主图（amz）—— 此前矛盾最严重的类型

```
【核心主体】
为电商商品生成一张高质量的【亚马逊主图】主视觉图。 【主体一致性 + 颜色锁定】参考图即本图要展示的商品本体：画面主体必须严格以参考图商品为准，外观、版型、轮廓、颜色、材质、图案纹理、logo 与标识、结构比例逐处一致，不得改变、重新设计或用其他款替换。商品颜色严格以参考图为准——本提示词中所有关于「色调 / 配色 / 色系」的描述仅作用于背景与场景氛围，绝不改变商品本体的颜色、图案或 logo。允许变化的仅限拍摄角度、视距（特写 / 全景）、背景与场景、构图方式、光影氛围与道具搭配——商品本身的外观身份与颜色必须保持不变。 适用电商平台：亚马逊。 目标市场与受众地域：全球。 无人物：画面仅展示产品/主体本身，不出现任何真人、模特、代言人、人物剪影或手部出镜；主体完整清晰占画面主体。 产品呈现：产品平铺俯拍，清晰呈现平面结构与整体轮廓。

【平台与硬性参数】
画质要求：8K 超高清，商业精修，高锐度，无镜头畸变；面料色彩1:1真实还原，无过度修饰与失真，保持商品原貌真实。 硬性规范：主体占画面≥85%；1:1 正方形构图；最小边长≥1000px。 背景规范：纯白背景（RGB 255,255,255），无场景、无道具、无额外装饰。

【构图规范】
构图规范：居中产品构图，完整展示服装版型；产品主体占画面约 65%，四周均匀留白，适配首屏主图规范。 版式要求：纯白背景，产品正面单图，符合亚马逊主图规范，无文字。

【背景与光影】
背景：纯白背景（RGB 255,255,255）。 色调：纯色背景不额外施加任何彩色色调，保持干净通透。 整体视觉风格：影棚柔光从侧上方打光，面料纹理高清晰呈现，肤质细腻通透，轻微立体轮廓光勾勒体积，整体无廉价过曝，商业高级感。 避免：过重阴影、暗沉低饱和、杂乱道具。

【风格与营销语义】
价值聚焦：视觉重心聚焦产品功能与使用场景，凸显实用性。 产品摆放形态：正面。 拍摄机位角度：平视。 产品价值仅通过产品材质肌理、工艺细节、柔和反光与精致光影等视觉细节传递高品质做工，全程不使用任何文字标注卖点。

【卖点传达】
核心卖点：「360度静音万向轮，承重强，适合办公」须作为画面视觉重点，通过构图重心、材质特写、光影强化、使用场景等视觉语言重点突出，绝不转为图上文字、字母、数字或标签。

【严格禁止】
文字约束：整张画面不出现任何文字、字母、数字、LOGO、水印、品牌名、价格、促销标语或标签；不将本提示词的需求、卖点、参数以文字形式呈现在画面中。 绝对禁止：肢体畸形、模特局部裁切、杂乱背景杂物、过重阴影、反光光斑、多余装饰摆件；以及把本提示词配置项 / 卖点 / 个性化要求写成图上文字、将参考图文字复制到生成图。参考图上的水印 / 价格签 / 背景文字 / 无关标签请忽略，不要复制到生成图；但参考图中的商品本体须严格还原，不得因忽略其上文字而改变商品外观。 负面提示词：模糊、畸变、低分辨率、多余文字、字母、数字、LOGO、水印、品牌名、价格、杂乱背景、过重阴影、反光光斑、人物、模特、人物剪影、手部出镜。 构图完整、主体突出、细节清晰、商业级质感，符合电商平台规范与大众审美。
```

## 首屏视觉图（hero，场景类，含人物 + 市场调色板）

```
【核心主体】
为电商商品生成一张高质量的【首屏视觉图】主视觉图。 适用电商平台：淘宝 / 天猫。 目标市场与受众地域：中东。 主体人物要求：适配中东审美的年轻女性模特，暖调健康肤色，柔和立体五官；纤细手臂、标准直角肩、匀称修长身形；全身完整入镜无裁切；简约淡系中东妆容、柔顺长发或低盘发；端庄舒展站姿，柔和大气；服装完整遮盖肩颈，拒绝暴露剪裁，符合中东大众审美。 人种肤色：中东暖调。 产品呈现：整体形态。

【平台与硬性参数】
画质要求：8K 超高清，商业精修，高锐度，无镜头畸变；自然肤质精修，不夸张瘦脸塑形，面料色彩1:1真实还原，无过度美颜失真。

【构图规范】
构图规范：居中全身构图，正面微侧约30°站姿，完整展示服装版型；人物主体占画面约 65%，四周均匀留白，适配首屏主图规范。 版式要求：首屏吸睛大图，强视觉冲击构图，主体突出有记忆点。

【背景与光影】
背景：浅金 / 米杏纯色轻奢渐变背景，禁止杂乱道具、花草、建筑干扰。 整体视觉风格：影棚柔光从侧上方打光，面料纹理高清晰呈现，肤质细腻通透，轻微立体轮廓光勾勒体积，整体无廉价过曝，商业高级感。 色调倾向：高饱和度色彩，鲜明浓郁，视觉冲击力强；配色参考中东轻奢背景色系：暖金、焦糖橙、宝石蓝、酒红。 避免：纯欧美冷白皮、夸张浓妆、西式极简冷白背景、过度性感动作、暴露剪裁。

【风格与营销语义】
价值聚焦：视觉重心聚焦面料质感与精细做工，凸显高品质。 视觉强化：产品主体与背景形成低对比色彩层次，突出主体不杂乱。 氛围浓度：极简纯色背景，仅微弱渐变光影，氛围占比≤10%，视觉重心100%在产品主体。 价值暗示：以精致可见的品质细节暗示价值，不靠文字。 产品价值仅通过服装面料垂坠肌理、立体缝线、柔和面料反光、细腻剪裁光影等视觉细节传递高品质做工，全程不使用任何文字标注卖点。

【严格禁止】
文字约束：整张画面不出现任何文字、字母、数字、LOGO、水印、品牌名、价格、促销标语或标签；不将本提示词的需求、卖点、参数以文字形式呈现在画面中。 绝对禁止：肢体畸形、模特局部裁切、杂乱背景杂物、过重阴影、反光光斑、多余装饰摆件；以及把本提示词配置项 / 卖点 / 个性化要求写成图上文字、将参考图文字复制到生成图。 负面提示词：模糊、畸变、低分辨率、多余文字、字母、数字、LOGO、水印、品牌名、价格、杂乱背景、过重阴影、反光光斑。 构图完整、主体突出、细节清晰、商业级质感，符合电商平台规范与大众审美。
```
