# 电商套图 · 配置区与规划列表重设计方案

> 待确认范围：重设计「全局输出配置」和「出图规划列表」两个区块；并在「AI 智能策划台」中新增「极速添加到列表」功能。不改动其他模块。

---

## 一、截图诊断

从当前截图看，两块都有明显的「样式丢失/不够精致」感：

### 全局输出配置
1. **区块边界感弱**：卡片底色和背景色太接近，看起来像贴上去的几个字段，不像一个独立功能区。
2. **字段拥挤**：模型 / 分辨率 / 数量 / 比例 4 个字段塞在一个 2×2 网格里，但字段高度和间距没有统一，数量步进器（− / +）与下拉框高度不一致，视觉节奏乱。
3. **标签字体淡**：字段标题 `label` 和输入控件之间没有清晰层级。
4. **步进器简陋**：看起来像普通按钮，没有品牌感。

### 出图规划列表
1. **头部与行动按钮挤压**：标题和「AI 智能策划台」按钮之间缺少空间节奏。
2. **规划项单行动作多**：一行里同时显示名称、标签、3 个参数芯片、复制/删除/设置 3 个操作，信息密度过高，且名称被截断为「产品…」，可读性差。
3. **参数芯片太素**：数量 / 比例 / 分辨率三个小标签没有图标或颜色区分，扫读困难。
4. **操作按钮靠太近**：复制、删除、设置三个按钮挤在右侧，容易误点。

---

## 二、重设计目标

- **全局输出配置**：做成视觉独立的「设置卡片」，字段清晰、间距舒适、步进器精致，让用户一眼看懂 4 个核心参数。
- **出图规划列表**：头部清爽，行动按钮突出，规划项改为「双行卡片」：上行名称+标签，下行参数芯片+操作，避免截断与拥挤。
- 保持现有设计系统 Token（颜色、圆角、阴影、字体），不引入新风格。
- 保持现有交互逻辑，只改视觉和布局。

---

## 三、方案 A（推荐）：卡片式精致布局

### 3.1 全局输出配置

结构保持不变，仍为可折叠 `config-section`，但内部重做：

- **卡片外壳**：白色背景 `#FFFFFF`，边框 1.5px `#ECEAE4`，圆角 12px，微阴影 `gb-sh-1`，与背景 `#F6F5F2` 拉开层次。
- **头部**：左侧图标 ⚙ + 标题「全局输出配置」，右侧折叠按钮。标题字号 15px、字重 700。
- **内容区**：4 个字段改用 **2 列网格**，但：
  - 每个字段外框改为独立「字段卡片」：浅灰底 `#FAF9F6`，圆角 10px，内边距 12px。
  - 字段标题在上方，字号 12px，字重 600，颜色 `#57555F`。
  - `Select` 高度统一为 38px，与步进器同高。
  - **步进器升级**：外框 1px `#DDDAD2`，圆角 8px；左右按钮 32×38px，hover 背景 `#F6F5F2`；中间数字宽度足够，字重 700。
- 4 字段排列：
  ```
  模型          分辨率
  每个类型出图数  图片比例
  ```
- 当未选择模型时，保留现有黄色提示文案，但放在卡片底部，使用带图标提示条样式。

### 3.2 出图规划列表

- **卡片外壳**：同全局输出配置（白底、浅灰边、12px 圆角、微阴影）。
- **头部**：
  - 左侧：`* 出图规划列表` + 已选计数 pill（`已选 1/50 个`）。pill 为深色底 `#1B1A21` 白字，醒目但不抢按钮。
  - 右侧：当已选 > 0 时显示「清空」按钮（灰色文字 + 垃圾桶图标）。
- **行动区**：
  - 主按钮 `✦ AI 智能策划台`：紫色渐变，高度 44px，圆角 12px，占据左侧 80%。
  - 次按钮 `+`：右侧 44×44px，紫色虚线边框，hover 变紫色实底 + 白字，用于快速添加。
  - 两按钮之间留 12px 间隙。
- **空状态**：显示大号图标 + 「暂无出图规划」+ 提示文案，引导点击 AI 策划台。
- **规划项卡片（PlanRow）**：
  - 左侧 3px 强调条：极速出图 = 紫，自定义 = 品牌橙。
  - 内边距 14px 16px，圆角 12px，白底，浅灰边，hover 上移 1px + 阴影加深。
  - **第一行**：序号 `#1.`（淡灰）+ 名称（不再截断，若太长则完整换行，但限定最大 2 行）+ 标签右对齐。
  - **第二行**：参数芯片带图标前缀，例如：
    - `🖼 数量 1`
    - `⬜ 比例 3:4`
    - `📐 分辨率 1K`
  - 芯片样式：浅灰底、圆角 7px、字号 11.5px，hover 略深。
  - **操作区**：复制 / 删除用 28px 圆角图标按钮，设置改为「设置 >」文字按钮，整体右对齐，按钮间距 6px。
  - 删除 hover 用红色警告背景，防止误点。
- **使用说明**：保留在列表底部，但使用更柔和的提示条样式，带 ℹ 图标。

### 3.3 AI 智能策划台 · 新增「极速添加到列表」

当前抽屉底部只有「取消」和「AI 智能策划 (N)」两个按钮：
- 「AI 智能策划」会添加已选类型，并**打开第一个新类型的属性设置弹窗**。
- 你新增的需求是：点击「⚡ 极速添加到列表 (N)」后，**直接添加已选类型到规划列表，不打开弹窗**。

实现方式：
- 在 `PlannerDrawer.tsx` 底部新增按钮：`⚡ 极速添加到列表 ({checked.size})`。
- 按钮样式：深色底 `#1B1A21` + 白字 + 闪电图标，与右侧紫色「AI 智能策划」按钮并列。
- 新增回调 `onQuickAdd(checkedIds: string[])`，在 `index.tsx` 中实现：
  1. 遍历所有新选中的 `type_id`；
  2. 调用 `createPlanItem(project.id, { type_id })`，使用后端默认的输出设置；
  3. 刷新项目状态；
  4. 关闭抽屉；
  5. 给出 `message.success` 提示。
- 当 `checked.size === 0` 时，按钮禁用并提示「请至少选择一个策划类型」。
- 如果已选类型已全部存在于当前规划列表中，则提示「所选类型已添加」或直接关闭。

> 注意：「极速添加」与「AI 智能策划」两个按钮共存，用户可按需选择。极速添加适合对默认设置满意的快速操作；AI 智能策划保留原有的引导式弹窗体验。

## 四、方案 B：极简行内布局（紧凑版）

如果左侧配置面板宽度有限（380px），方案 A 可能略宽，可选方案 B：

- 全局输出配置：4 字段改为 **1 列纵向排列**，每行「标签 + 控件」横向排布，节省垂直空间但增加高度。适合字段标题较长时。
- 出图规划列表：规划项改为 **单行** 但只显示 2 个参数，剩余参数 hover 后显示 tooltip，操作按钮在 hover 时才出现。信息更简洁，但鼠标依赖更强。

> 方案 A 更平衡「信息完整」和「美观」，推荐采用。
